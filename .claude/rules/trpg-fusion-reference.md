# 참고 자료 — TRPG 하우스룰의 융화체 시스템

**이 문서는 설계 결정이 아니다.** 제작자가 하우스룰 TRPG에서 굴리던 기존 시스템의 **원본 기록**이다.
현재 만드는 게임의 "자원 배분(태양 핵 식)" 시스템이 여기서 유래했다.

이 문서를 **규칙으로 읽지 말 것.** 여기 적힌 효과는 TRPG 전용 시스템에 의존하며,
그 시스템들이 새 게임에 존재하는지는 대부분 미정이다. 아래 "이식 문제" 참조.

## 원본 TRPG의 계보

제작자 설명: **페이트 코어 기반 + Lobotomy Corporation / Library of Ruina의 시스템 + 명일방주의 직군**을 융합한 하우스룰.

- 페이트 코어 → 기능, 보정, 액션 판정
- Lobotomy Corporation / Library of Ruina → 속도 주사위, 감정 단계·감정 코인, 데미지 단계, 대결(액션 승패), 격차, 환상체 책장, 정신력
- 명일방주 → 직군 (캐릭터가 검술 / 속성마법 등 서로 다른 전문 축을 가진다)

원본은 Roll20 표이며, 아래는 그 내용을 옮긴 것이다. 캐릭터 3명의 예시가 기록되어 있다.

## 구조 분석 (AI의 읽기 — 제작자 확인 필요)

아래는 세 캐릭터의 표를 비교해 읽어낸 구조다. **확인되지 않았다.**

### 그리드는 캐릭터마다 존재하며, 슬롯 수가 다르다

| | 긍정 영혼 | 부정 영혼 | 총 슬롯 |
|---|---|---|---|
| 캐릭터 1 | α β γ δ (4) | α β γ δ (4) | 8 |
| 캐릭터 2 | α β γ (3) | α β γ (3) | 6 |
| 캐릭터 3 | α β γ (3) | α β γ (3) | 6 |

→ **δ(희망/광기의 영혼)는 캐릭터 1에만 있다.** 성장이나 등급 차이로 슬롯이 늘어나는 구조로 추정.

### 영혼 이름은 고정된 틀이다

긍정은 α 쇄신 / β 용맹 / γ 충심 / δ 희망, 부정은 α 쾌락 / β 복수 / γ 거짓 / δ 광기 —
**세 캐릭터 전부 동일하다.** 영혼은 캐릭터별 개성이 아니라 **공통 슬롯 이름**이다.

### 코스트 티어도 고정이다

각 영혼의 세 후보는 항상 **0 / 중 / 고** 구조다. 특히 아래 자리는 세 캐릭터에서 코스트가 완전히 같다:

| 자리 | 코스트 |
|---|---|
| 긍정 α | 0 / 5 / 25 |
| 부정 α | 0 / 5 / 25 |
| 부정 β | 0 / 25 / 50 |
| 부정 γ | 0 / 50 / 100 |

→ **코스트는 슬롯이 정하고, 캐릭터가 정하지 않는다.**

### 긍정 / 부정 결집체의 의미 — 제작자 확인됨

**Library of Ruina 쪽 감각을 가져온 것이다.**

- **긍정 결집체 = 순수 메리트.** 디메리트 없이 그냥 좋아진다.
- **부정 결집체 = 리스크를 감안해야 하는 큰 리턴.** 대가가 따르지만 효과가 크다.

표를 보면 그대로 드러난다. 부정 쪽의 고티어는 전부 대가가 붙어 있다:
리틀 데자이어(방어력 -3), 램페이지 스펙터(HP 1 / 코인 획득 불가), 피니스 템포리스(3사이클 후 패배 / 턴마다 누적 피해 / 행동마다 코인 5 소모), 브로큰 세이비어(턴마다 HP -5).
반면 긍정 쪽 고티어(결전자, 최강, 원탁 아래서, 은은한 향수)는 디메리트가 없다.

→ **부정 결집체의 β·γ 라인이 전부 여기 해당한다.** 즉 부정 쪽은 거의 통째로 "네 고유 기믹을 증폭시키되 대가를 치른다" 전용 라인이다.

**3) 완전 고유** — 이름부터 캐릭터마다 다르다

- 긍정 α 0코스트: 또 하나의 정신 / 영원한 의지 / 정신의 갑옷
- 긍정 β 전체: (질풍신뢰·경계돌파·최강) / (전력전개·잿가루의 향·기록된 의지) / (매서운 힘·격류를 향해·태초의 불)
- 긍정 γ 중·고: 캐릭터마다 다름

→ **긍정 결집체가 캐릭터 개성(직군)을 담는 자리**로 보인다. 캐릭터 2는 검술, 캐릭터 3은 속성마법.

### 고유 기믹은 캐릭터마다 하나씩 있다

- 캐릭터 1 — **대역**: 교체 가능한 두 번째 몸/분신으로 보인다
- 캐릭터 2 — **엔드레이트**: 지속 시간이 있는 상태
- 캐릭터 3 — **침식**: 상태. 진입 시점이 있다 ("침식 후")

**중요**: 대역은 게임 전역 시스템이 아니라 **캐릭터 1의 고유 기믹**이다.
(이전 분석에서 전역 시스템으로 잘못 읽었다. 정정됨)

### 0코스트만으로도 그리드가 꽉 찬다

캐릭터 2는 긍정 0/12, 부정 0/0이고 **모든 슬롯이 0코스트로 채워져 있다.**
→ 자원을 전혀 쓰지 않아도 빌드가 성립한다. 자원은 **업그레이드**이지 전제가 아니다.

### 헤더 숫자 = [사용 중 코스트 합 / 보유 자원] — 제작자 확인됨

- 캐릭터 2·3: 전부 0코스트 사용 → **0** / 보유량. 일치.
- 캐릭터 1 부정: 5+25+50+150 = **230** / 235. 일치.
- 캐릭터 1 긍정: 활성 합이 355인데 **280**으로 적혀 있다 → **시트를 수정한 뒤 합계를 갱신하지 않은 것.** 구조상의 의미는 없다.

### 자원 보유량 차이는 플레이 시간 차이다 — 설계상의 제약이 아니다

캐릭터 1(368/235)과 캐릭터 2·3(12/5, 0/0)의 격차는 **TRPG를 얼마나 오래 굴렸는지의 차이**다.
캐릭터 1은 오래 플레이해서 자원이 많이 쌓였고, 2·3은 적게 해서 안 쌓였다.

**원본 TRPG에서 자원은 세션을 거듭할수록 누적되는 영구 성장이었다.**

→ 이전 분석에서 "예산이 부족해서 최고 티어를 전부 못 산다(368 < 375)"를 **설계된 제약으로 읽었으나, 그것은 우연이다.** 정정됨.
→ 단, 새 게임은 로그라이크이고 **죽으면 쌓인 자원이 날아간다.** 따라서 런 내부에서는 자원이 자연히 희소해진다. (아래 "새 게임으로 옮길 때" 참조)

## 이식 문제

여기 적힌 효과들은 **새 게임에 존재하지 않거나 미정인 시스템**을 참조한다.

### 새 게임에서 이미 제거된 것

- **속도 주사위** — 스피드 수치 제거 확정. 의존: 최강, 희망의 달, 창백한 재, 블레이드 왈츠(캐릭터 2)

### 새 게임에 없는 전투 구조

원본은 Library of Ruina식 **대결(clash)** 구조다. 속도 주사위로 순서를 잡고, 액션끼리 맞붙어 승패와 격차가 나온다.
새 게임은 **턴 노트 + 리액티브 방어**이고 대결이 없다. 따라서 아래에 의존하는 효과는 전부 다시 써야 한다.

- **액션 승패** — 믿음의 기록, 램페이지 스펙터(1), 루나 폴, 흔적 추출자, 잿가루의 향
- **데미지 단계** — 경계 돌파, 믿음의 기록, 집념의 검, 최후의 파동, 태초의 불, 램페이지 스펙터(2·3), 고독한 환각(3)
- **격차** — 경계 돌파, 루나 폴

### 새 게임에 존재하는지 미정인 것

- **정신력** (체력과 별개 자원) — 기사회생, 고독한 환각(1), 집념의 검, 잿가루의 향, 기록된 의지, 결전자, 환상 무도회, 흔적 추출자
- **감정 단계 / 감정 코인** — 창백한 재, 영원한 갈증, 환상 무도회, 냉정과 격렬, 램페이지 스펙터(3), 피니스 템포리스(3)
- **환상체 책장** — 격류를 향해, 고독한 환각(3), 보복 프로토콜(3)
- **기능 / 운동능력 / 내성 단계 / 검술 / 속성마법** — 페이트 코어식 능력치 + 명일방주식 직군축
- **원소 피해 / 상태이상** — 속성 체계 미정. 엔도르핀, 결전자
- **운명점** — 원탁 아래서
- **서포트 캐릭터** — 은은한 향수
- **각 캐릭터의 고유 기믹** (대역 / 엔드레이트 / 침식) — 새 게임에서 이 설계를 유지할지 미정

→ **24개 중 그대로 이식 가능한 것은 극소수다.** 운명에의 저항(피해 흡수), 리틀 데자이어(공격력/방어력), 피카레스크(조건부 회복), 브로큰 세이비어·패러렐 메트로놈(HP 조건부, "기능"을 다른 것으로 바꾸면) 정도.

### 이식 가치가 있는 것은 효과가 아니라 설계 패턴

- **그리드 = 고정 슬롯 틀 + 캐릭터별 내용물.** 영혼 이름과 코스트 티어는 공용, 효과는 캐릭터별
- **긍정은 직군(개성), 부정은 고유 기믹 증폭** 으로 역할이 갈린다
- **슬롯당 택1 + 0코스트 후보 상비** → 자원 0에서도 빌드가 성립
- **코스트 티어 분리 + 예산 부족** → 어디에 몰아줄지가 결정이 됨
- **고티어에 강한 디메리트** → 피니스 템포리스(3사이클 후 패배), 브로큰 세이비어(턴마다 HP -5), 램페이지 스펙터(HP 1), 리틀 데자이어(방어력 -3).
  고코스트가 상위호환이 아니라 **도박**이 된다
- **공용 융화체를 섞어 둠** → 캐릭터마다 전부 새로 쓰지 않아도 그리드가 채워진다

## 새 게임으로 옮길 때 달라지는 것

### 자원이 영구 누적 → 런 한정

원본 TRPG에서 자원은 **세션을 거듭하며 영구 누적**됐다. 캐릭터 1의 368이 그 결과다.
새 게임은 로그라이크이므로 **죽으면 쌓인 자원이 날아간다.**

이 차이가 만드는 효과:

- **런 초반에는 0코스트만 쓸 수 있다.** 0코스트 후보들이 사실상 그 캐릭터의 기본 빌드가 된다.
- **런이 진행되며 고티어가 열린다.** 그리드 자체가 런의 성장 곡선이 된다.
- **재배분이 자유로워도 결정이 남는다.** 런 내부에서는 자원이 항상 모자라므로 "지금 무엇에 몰아줄까"가 실제 판단이다. (영구 누적이었다면 결국 다 사게 되므로 결정이 사라진다)

### 코스트 수치는 재조정이 필요하다

원본의 0 / 5 / 25 / 50 / 75 / 100 / 150 티어는 **여러 세션에 걸친 누적을 전제로 설계된 값**이다.
런 하나(수십 전투 정도) 안에서 의미 있는 선택이 가능하려면 **획득량과 코스트를 런 길이에 맞춰 다시 잡아야 한다.**
원본 수치를 그대로 쓰면 보스까지 가도 0코스트만 쓰게 될 가능성이 높다.
