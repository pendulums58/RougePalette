# 계승의 장

턴제 로그라이트. Vite + 바닐라 TypeScript.

> **현재 단계: 구현 틀 완성, 수치 미정.**
> 아래 확정 규칙이 전부 돌아간다. **모든 수치는 플레이스홀더**이며 설계 결정이 아니다.
> 미정 항목(배분 그리드 구조, 적의 방어, 안티스톨, 역공·다이스·속성 등)은
> 임의로 채우지 않고 연결 지점만 열어 뒀다. 기준은 [`.claude/rules/design.md`](.claude/rules/design.md).

## 어떤 게임인가

아래는 `design.md`에서 **확정**된 것만 옮긴 것이다. 미정 항목은 그다음 절에 있다.

용어 두 개를 먼저 구분한다. **턴** = 1회 행동(스킬 하나 사용). **사이클** = 행동 가능한 전원이 행동을 끝내기까지.

### 기본 구조

- **카드 게임이 아니다.** 플레이어는 **스킬**을 사용한다.
- 조작하는 캐릭터는 **1명**. 파티제가 아니다.
- 턴 순서는 슬레이 더 스파이어식 **진영 단위** — 내 턴을 끝내면 적 턴.
  (*"일단" 확정 — 역공 안과 엮여 바뀔 수 있다*)
- 스피드 · 속도 수치는 쓰지 않는다.

### 턴 노트

행동권 수치. 스킬 사용에 소모한다.

- 캐릭터마다 기본값이 다르다.
- **매 사이클 리필된다.**
- 남아 있는 한 자기 차례에 여러 번 행동할 수 있다.
- **행동과 방어 양쪽에 쓰는 공용 자원이다.** 별도 자원이 아니다.

### 과부하

- 사이클 중 행동할 때마다 **1씩 쌓인다.**
- 행동 스킬의 코스트가 **현재 과부하만큼 증가한다.** (1코스트 스킬 연속 사용 → 1, 2, 3 ...)
- **방어 스킬은 과부하를 쌓지도 않고, 쌓인 과부하의 영향도 받지 않는다.** 과부하가 100이어도 1코스트 방어 스킬의 소모량은 1이다.
- **사이클 종료 시 사라진다.**

싼 공격을 난사해 적의 방어 자원을 빼는 전략을 억제하기 위한 장치다.

### 방어 — 리액티브

미리 선언하지 않는다. 적의 공격 스킬이 플레이어를 지정하는 **그 순간** 고른다.

- **방어 스킬 사용** → 피해 일정량 경감 (턴 노트를 소모한다)
- **방어 안 함 선언** → **무방비**. 더 큰 피해를 받는다

### 강화 레이어

런 중에 **강화**를 획득해 누적한다. **런이 끝나면 사라진다** (영구 성장이 아니다).

두 경로를 **둘 다** 쓴다.

1. **무작위 제시** — 런 중 제시되는 강화를 획득 (붕괴: 스타레일 차분화 우주 쪽)
2. **자원 배분** — 자원을 모아 투자해서 올린다 (스타크래프트 2 태양 핵 쪽)

- 배분은 **재배분(교체)이 자유롭다.** 휴식 지점의 기회를 소모하지 않는다 — 둘은 별개 시스템이다.
- 배분 자원은 **캐릭터마다 다르고 런 한정**이다. 죽으면 쌓인 자원이 날아간다.
- **긍정 = 순수 메리트**(디메리트 없음) / **부정 = 리스크를 감안해야 하는 큰 리턴.** 역할이 갈린다.
- 공용 강화와 캐릭터 전용 강화를 섞는다.

이 시스템은 제작자의 하우스룰 TRPG에서 유래했다. 원본 기록은 [`trpg-fusion-reference.md`](.claude/rules/trpg-fusion-reference.md).

### 맵

- 맵은 **특정 알고리즘 하에 매 런 무작위로 생성된다.**
- 슬레이 더 스파이어처럼 **올라가는 분기 구조가 화면에 보인다.** 직전 노드에서
  이어지는 곳으로만 갈 수 있다.
- **n층마다 휴식 지점이 확정으로 등장한다.**
- **n층마다 보스가 확정으로 등장한다.**
- **경로가 서로 교차하지 않는다.** (X자로 엇갈리는 모양은 쓰지 않는다)
- **노드 종류**: 전투 / 정예 / 휴식 지점 / 보스 / 상점 / 이벤트
- (*1막/2막/3막 구조로 갈지는 미정*)

### 화폐

- **골드가 있다.** 상점에서 쓰는 화폐다.
- **전투 보상과 이벤트에서 얻는다.** 정예와 보스는 더 많이 준다 (STS 레퍼런스).
- **상점에서는 스킬을 판다.** (그것만 확정 — 제거·포션·유물류는 미정)
- 강화 배분에 쓰는 자원(긍정/부정)과는 **별개다.**
- (*추가 화폐를 하나 더 둘지는 미정*)

### 휴식 지점 / 무작위성

- 휴식 지점에서 무엇을 할지 고르는 **선택 구조는 채택한다. HP 회복**은 선택지로 확정.
- 무작위성은 **런 레이어에만** 있다 — 전투 후 스킬 획득, 강화 제시. 전투 내부에는 현재 무작위 요소가 없다.

## 아직 정해지지 않은 것

- **수치 전반** — 캐릭터별 턴 노트 기본값, 스킬 코스트 분포, 무방비 배율, 방어 경감량, 적 체력 · 공격력, 휴식 지점 간격
- **방어 선택의 깊이** — "방어 안 함"이 유효한 선택이어야 하는가, 방어 스킬을 미리 세팅하는가 (두 질문은 연동)
- **무방비 디메리트의 유효성** — TRPG 원본에 없던 새 시스템이고 아직 플레이로 검증되지 않았다
- **강화 세부** — 자원 획득 조건, 배분 그리드 구조, 자원 풀 개수, 재배분 제약
- **맵** — 1막/2막/3막 구조를 쓸지, 휴식·보스 간격(n)의 값, 맵의 폭과 총 층 수,
  각 노드 종류의 등장 빈도
- **골드 획득량과 가격대**, 스킬 말고 상점에 또 무엇을 둘지, 추가 화폐를 둘지
- **스킬의 오토배틀러식 중복 강화**, **유물 비슷한 시스템** (둘 다 제작자 발의)
- **이벤트의 내용** (텍스트 조우 쪽으로 기울어 있으나 확정은 아니다)
- **안티스톨 방식, 캐릭터 해금, 다이스 · 역공 · 속성 도입 여부**

전체 목록과 각 항목의 상태(미정 / 제작자 발의 / AI 제안)는 [`design.md`](.claude/rules/design.md) 참조.
