# 이름 없는 덱빌더

턴제 덱빌딩 로그라이트. Vite + 바닐라 TypeScript.

## 돌려보기

```bash
npm install
npm run dev
```

## 지금 되는 것

- 캐릭터 선택 (검사 / 학자)
- 층마다 갈림길 2개 중 선택 — 전투 / 정예 / 모닥불, 마지막은 보스
- 턴제 카드 전투: 에너지, 방어도, 뽑을·버린·소멸 더미, 적 의도 표시
- 상태이상: 힘, 약화, 취약, 재생
- 전투 보상으로 카드 3장 중 1장 획득
- 모닥불에서 회복 또는 덱에서 카드 제거
- 시드 기반 난수 — 같은 시드면 같은 런

## 아직 없는 것

유물, 상점, 카드 강화, 저장/불러오기, 사운드, 애니메이션.

구조와 작업 요령은 `CLAUDE.md` 참고.

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 빌드해서 GitHub Pages에 올린다.
레포 **Settings → Pages → Source** 를 **GitHub Actions** 로 한 번 바꿔주면 그다음부터는 자동.
